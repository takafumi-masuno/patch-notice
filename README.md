# Patch Notice のデータ

[Patch Notice](https://takafumi-masuno.github.io/patch-notice/) の公開データです。main ブランチの `.github/workflows/update.yml` が6時間ごとに更新します。手で編集しないでください。

| ファイル | 内容 |
|---|---|
| `items.json` | 公開用の項目（直近90日分）。本文は含みません |
| `status.json` | 情報源ごとの取得結果 |
| `state.json` | 次回の差分取得に使う値と KEV の CVE 一覧 |
| `summaries.json` | AI 要約。本文は含みません |

各項目の出典と帰属表示は [情報源のページ](https://takafumi-masuno.github.io/patch-notice/sources/) を参照してください。各社や各機関とは関係のない、個人のサイトです。
